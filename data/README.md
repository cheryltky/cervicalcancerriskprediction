# Data

`cervical-cancer-risk.csv` is the cervical cancer screening dataset from the
UCI Machine Learning Repository, as stated in the original project README. The
exact dataset page title and URL were not recorded in the original README or
notebook, so check the repository before citing it.

- One row per patient, 858 rows and 36 columns (from the notebook output).
- Missing values are stored as `?`.
- Columns cover demographics, sexual and reproductive history, smoking,
  contraceptive use, STD history, earlier diagnoses and four screening test
  results: Hinselmann, Schiller, Citology and Biopsy.
- The data is anonymised, but it describes individual patients' health. Do
  not add other patient-level data to this repository.
